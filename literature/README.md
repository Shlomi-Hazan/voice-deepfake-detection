# Literature

One folder per paper, numbered by reading order. Each folder holds four documents,
each as `.md` (source) and `.pdf` (built):

| File | Language | Purpose |
|---|---|---|
| `research-card.he` | Hebrew | In-depth working document |
| `research-card.en` | English | Direct translation of the above |
| `academic-summary.he` | Hebrew | Text for the shared literature review |
| `academic-summary.en` | English | Direct translation of the above |

Content is written in the ChatGPT workflow and dropped in here as-is.
Translations are direct and exact; technical terms stay in English.
